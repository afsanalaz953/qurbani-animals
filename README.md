Project Name:
Qurbani Hut

Project Description: Its a collection of animals list for Qurbani, where their details informations are stored. When someone select individual animals they can see the details and also know about their features. There is also a booking form from where user can easily purchase the selected animals.

🚀 Tech Stack
Framework: Next.js (App Router)
Language: JavaScript
Styling: Tailwind CSS


📦 key features of the project
-You can see the project on vercel 
- You can sort animals by pricing
- You can see animals details with image
